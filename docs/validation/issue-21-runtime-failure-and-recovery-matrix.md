# Issue #21 Runtime Failure and Recovery Matrix

**Status:** Slice 7 validation artifact
**Date:** 2026-08-14

This matrix covers failures that can occur after structurally valid data and
initial application validation have entered a projection/export/disposition
workflow.

| ID | Failure point | Unsafe response | Required response |
| --- | --- | --- | --- |
| `F01` | source changes after privacy projection but before export acceptance | write export from stale projection | re-resolve/revalidate; stale candidate/export attempt must not be accepted |
| `F02` | policy definition changes mid-export | silently use new policy | bind one exact policy version/digest or restart as new export |
| `F03` | authorization decision changes mid-export | continue because request started earlier | revalidate exact accepted authorization at commit boundary |
| `F04` | manual-review result references prior decision digest | accept reviewer label | reject digest mismatch and return to review |
| `F05` | output renderer crashes before final artifact creation | create receipt anyway | no accepted export receipt until artifact is durably verified |
| `F06` | artifact created but receipt write crashes | regenerate artifact on retry | recover exact artifact and create only missing receipt if all evidence reconciles |
| `F07` | receipt written but Operation Journal not committed | assume complete | recover exact operation; verify artifact+receipt before commit |
| `F08` | output read-back digest differs | publish anyway | stop/recover; do not mark export accepted |
| `F09` | historical export later becomes policy-disfavored | rewrite bytes in place | create successor/restriction/disposition workflow; historical export remains immutable |
| `F10` | source is Exceptionally Removed after old cache was built | rebuild old content from cache | remove/ignore stale derived content; do not resurrect |
| `F11` | access request hold appears after retention dry-run | execute old plan | mark candidate stale/blocked and re-evaluate |
| `F12` | retention policy version changes after dry-run | execute old date computation | new plan revision/re-evaluation |
| `F13` | disposition authorization scope changes after dry-run | use broad prior plan | candidate stale/unresolved unless exact current authorization still covers action |
| `F14` | Portia Operation Journal becomes in-progress due to another operation | delete anyway | block candidate until Portia recovery/preconditions clear |
| `F15` | correction/disagreement graph changes after plan | delete prior candidate set | stale plan; recompute coherent unit |
| `F16` | canonical delete commits; derived cleanup crashes | report complete | recover forward; remove stale derived content before truthful completion |
| `F17` | derived cleanup succeeds; canonical mutation did not commit | assume canonical deleted | reconcile authoritative source; rebuild derived state as required |
| `F18` | export bytes delete commits; provenance cleanup fails | recreate bytes to roll back | preserve partial truthful state; no compensating resurrection |
| `F19` | Portia action succeeds; required Core action fails | report cross-module completion | partial/unresolved cross-module result |
| `F20` | Portia and Core succeed; outside backup unknown | report all copies destroyed | report bounded suite results plus outside-control uncertainty |
| `F21` | orchestrator restarts after ambiguous module response | replay delete | ask module to reconcile exact plan item first |
| `F22` | target file already missing but no operation evidence | mark completed | unresolved/integrity diagnosis; missing file alone proves nothing |
| `F23` | foreign owner reports unsupported contract | Portia deletes local references to hide unresolved state | preserve truthful reference/history; mark foreign action unresolved |
| `F24` | Vitrine immutable copy exists while Portia source is disposed | attempt to rewrite Vitrine | treat Vitrine as separate governed custody |
| `F25` | aggregate query yields rare cell unexpectedly | return because policy threshold passed earlier | re-evaluate result-specific re-identification risk |
| `F26` | free-text redaction unexpectedly changes proposition | emit edited text | require manual review; no synthetic paraphrase |
| `F27` | restricted Communication enters broad export due to source graph expansion | include because export was already authorized generally | field-level policy still applies; withhold/manual-review |
| `F28` | unsupported future source field appears | pass through unknown field | fail closed |
| `F29` | requested source artifact is unavailable | convert to no-evidence | preserve `unavailable` semantics |
| `F30` | same output bytes generated by two deliberate export requests | merge receipts by digest | preserve distinct `pexp_` identities |
| `F31` | old export superseded by new one | delete old automatically | supersession alone has no deletion authority |
| `F32` | routine retention action encounters Exceptional Removal certificate | recursively remove certificate | preserve certificate according to its independent retention policy |
| `F33` | user cancels dry-run review | execute nothing | leave custody unchanged |
| `F34` | plan is partially authorized across modules | broaden to common denominator | execute only exact authorized items/actions |
| `F35` | module verification cannot determine external-copy status | guess completed | bounded local success + unresolved/outside-suite result |
| `F36` | diagnostic privacy metadata contains sensitive source text | persist for convenience | privacy-minimize diagnostic/plan evidence |
